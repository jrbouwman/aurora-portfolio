# Herframe: Van Analoge Pen naar Digitale Authenticatie

*Bron: Huiswerk voorbereiding les 7 (presentatie)*

## Het herframe

Twee ideeen bedacht (kluisje en pasje), maar niet ideaal omdat het nog steeds fysiek is. Daarmee is de value niet extreem groot. Dus: digitaal.

## Nieuwe ideeen
- Raboscanner-achtig device
- Authenticatie zonder handtekening, meer procesgericht

## Hoe zijn we hier gekomen

1. **Probleem:** handtekeningen zijn onbetrouwbaar
2. **Eerste oplossingen:** kluisje, pasje + pen
3. **Probleem bleef:**
   - Nog steeds fysiek
   - Nog steeds fraude mogelijk
4. **Inzicht:** het probleem zit in de handtekening zelf
5. **Nieuwe richting:** digitaal + authenticatie i.p.v. handtekening

## Value van de nieuwe richting

**Veiliger:**
- Moeilijk te vervalsen
- Identiteit gekoppeld aan actie

**Efficienter:**
- Sneller
- Geen papier/pen nodig

**Toegankelijker:**
- Op afstand mogelijk
- Altijd beschikbaar
